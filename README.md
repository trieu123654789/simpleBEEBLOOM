# simple.CTU.VU2 (simpleBEEBLOOM)

## Tổng quan dự án
Dự án mô phỏng giáo dục thực tế ảo (VR) và Desktop xoay quanh chu kỳ xâm nhập mặn, canh tác nông nghiệp, nuôi trồng thủy sản và cơ chế sinh thái thụ phấn hoa (Bee Bloom) tại Đồng bằng Sông Cửu Long.

## Cấu hình Scene chính
- **Scene Build chính**: `Assets/Scenes/VU2/SCN_BeeBloom.unity`
- **Scene Mô phỏng nông nghiệp VU2**: `Assets/Scenes/VU2/SCN_VU2_Level1_New.unity`

## Công nghệ & Thư viện
- **Unity Engine**: Unity 2022.3 LTS (URP)
- **XR Interaction Toolkit**: VR locomotion, direct/ray interactors, XR Device Simulator
- **Mã nguồn chính**: `Assets/Scripts/VU2`
